# Fun AI Chatbot

A simple, family-friendly AI chatbot made with HTML and JavaScript.

It runs entirely in your browser — no installation needed!

## Features
- Says hello
- Tells jokes
- Shares cool facts
- Talks about space
- Super easy to customize

## How to use
1. Open `index.html` in any web browser, **or**
2. Visit the GitHub Pages site (once enabled)

## Enable GitHub Pages
1. Go to the repository Settings
2. Click **Pages** in the left sidebar
3. Under "Source", choose the `main` branch and `/ (root)`
4. Click Save

Your chatbot will be live at:  
`https://Glitchplays1.github.io/fun-ai-chatbot/`

Have fun!
