1. ABOUT THIS DATABASE
============================================================

This text file is a starter reference for collecting information about games of many kinds: video games, mobile games, PC and console games, virtual-reality games, tabletop games, board games, card games, sports, playground games, and traditional games.

IMPORTANT LIMIT:
There is no single complete list of every game ever created. New games are released constantly, many older or regional games have incomplete records, and game titles can be shared by different games. This file is a useful starter database, not an exhaustive record of every game in the world. Verify facts with linked sources before publishing or relying on them.

Suggested fields for each database record:
- Game title
- Alternate title / original title
- Game type and genre
- First release date (and region, if relevant)
- Developer / creator
- Publisher (if applicable)
- Platforms or equipment needed
- Single-player / multiplayer
- Short description
- Main modes / rules / objectives
- Notable characters or pieces
- Official website
- Reliable reference links
- Information status: verified / needs verification / unknown
